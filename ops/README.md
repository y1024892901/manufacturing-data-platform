# ops/ — 运维与工具

## 技术栈
Bash（Git Bash 兼容）/ PowerShell · Python · SQL · Docker CLI · Prometheus + Grafana（可选）

## 职责
让系统**可启动、可巡检、可恢复、可演示**。

## 放什么代码 / 文件

```
ops/
├── scripts/     启停、重置、演示准备脚本
├── sql/         常用运维 SQL（巡检、清理、统计）
├── monitoring/  监控与告警配置
└── backup/      备份与恢复
```

## 干什么事情
1. **一键启动**：`start.sh` 拉起全栈并等待服务就绪（不只是 `docker compose up`，还要做健康检查）
2. **一键重置**：`reset.sh` 清空数据并重新造数，保证演示可反复重来（**演示前的救命脚本**）
3. **一键演示准备**：`demo_prep.sh` 执行完整流程 —— 重置 → 造数 → 采集 → 建模 → 训练 → 校验，
   最后打印"演示就绪"检查清单
4. **巡检**：检查各服务状态、数据新鲜度、质量通过率、磁盘占用
5. **备份恢复**：演示前的数据库快照，出问题 30 秒回滚
