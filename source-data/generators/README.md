# source-data/generators/ — 各业务系统造数模块

## 技术栈
Python 3.11 · Faker（中文 locale `zh_CN`）· numpy（数值分布）· psycopg2 / SQLModel（写库）

## 放什么代码

| 模块 | 模拟系统 | 生成内容 | 关键约束 |
|---|---|---|---|
| `mdm.py` | 主数据 | 客户、产品、物料、设备、供应商、成本中心、员工 | **先于所有业务数据生成**，是全链路主键来源 |
| `crm.py` | CRM | 客户信息、销售商机、商机阶段流转 | 商机转化率在合理区间 |
| `plm.py` | PLM | 产品、BOM 多层结构、工艺路线、工序 | BOM 展开正确，工序顺序合法 |
| `srm.py` | SRM | 供应商、采购订单、到货记录 | 到货时间影响齐套 |
| `erp.py` | ERP | 销售订单、生产订单、财务凭证、应收账款 | 一单一行特征表的源头 |
| `mes.py` | MES | 工单、工序、报工记录、生产实绩 | 报工累计不超过计划量 |
| `wms.py` | WMS | 库存余额、出入库流水、库位 | 库存守恒 |
| `qms.py` | QMS | 检验记录、不合格品、返工 | 不良率与返工量正相关 |
| `eam.py` | EAM | 设备台账、故障维修、点检记录 | 故障与停机时段一致 |
| `energy.py` | 能源 | 设备能耗、车间能耗 | 与设备运行时长正相关 |

## 生成顺序（强依赖，不可打乱）

```
mdm（主数据）
  └─→ crm / plm
        └─→ srm
              └─→ erp（销售订单 → 生产订单）
                    └─→ mes（工单 → 报工）
                          ├─→ wms（库存变动）
                          ├─→ qms（检验）
                          ├─→ eam（故障/点检）
                          └─→ energy（能耗）
                                └─→ erp（财务凭证/应收，依赖前序结果）
```

## 干什么事情
1. 每个模块实现统一的 `generate(conn, cfg) -> Stats` 接口，便于编排与统计
2. 模块间通过**主数据 ID 集合**传递依赖，不硬编码 ID
3. 所有模块支持 `--scale` 参数控制数据量档位（演示用小档，压测用大档）
