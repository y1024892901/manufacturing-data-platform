# source-data/seeds/ — 造数种子与配置

## 技术栈
YAML（人类可读可编辑）· JSON（机器读取）

## 放什么代码

| 文件 | 内容 |
|---|---|
| `profile_demo.yaml` | 演示档：订单 300 单、工单 1200 张、报工 8000 条——够演示且秒级生成 |
| `profile_full.yaml` | 完整档：放大 20 倍，用于验证性能与 dbt 测试规模 |
| `profile_small.yaml` | 冒烟档：每表几十行，用于单元测试与快速回归 |
| `mdm_master.yaml` | 主数据字典：客户名单、产品族、物料分类、设备清单、供应商池 |
| `business_params.yaml` | 业务参数：良率区间、采购提前期、设备故障率、能耗基线、季节系数 |
| `fake_text.yaml` | 中文假数据词库：客户名、产品名、故障描述、处置建议文本 |

## 干什么事情
1. **业务参数集中管理**——调整良率或故障率只需改 YAML，不用改代码
2. 演示前若数据量不合适，改 `profile_demo.yaml` 的数字重新生成即可
3. `fake_text.yaml` 让生成的故障描述、处置建议读起来像人话，演示可信度大幅提升
4. 所有配置随代码入库，保证**换台机器生成的数据一模一样**
