# 能源管理系统（EMS）当前状态

> 更新日期：2026-09-28。字段设计依据见 [能源字段参考](../../docs/energy-field-reference.md)。

## 已交付页面

能源首页、能源仪表与采集点、设备能耗、车间能耗、能耗异常告警均有中文页面。四类业务记录提供列表、详情、新增、编辑和删除；列表支持关键字筛选和分页。服务端错误由统一 HTTP 拦截器显示中文提示。

| 页面 | 接口 | 主要能力 |
|---|---|---|
| 能源仪表与采集点 | `/api/energy/meters` | 仪表层级、能源类型、计量单位、位置、倍率、采集周期、校准日期、数据来源与负责人 |
| 设备能耗 | `/api/energy/usages` | 按设备、日期、时段和介质维护读数；关联启用仪表；自动算单位能耗和基线偏离 |
| 车间能耗 | `/api/energy/workshop-usages` | 按车间、日期和介质维护汇总；自动算单位能耗和基线偏离 |
| 能耗异常告警 | `/api/energy/alerts` | 管理自动生成或人工登记的告警、责任人、期限、原因和处置措施 |

## 数据与校验

- 能耗值、产量、运行小时、基线、阈值和倍率不能为负数；小时必须在 0 至 23 之间。
- 同一设备在相同日期、小时和能源类型下不能重复；同一车间在相同日期和能源类型下不能重复。更新时排除当前记录。
- 能耗类型、计量状态、仪表类型、告警等级和告警状态均由服务端校验。绑定的设备仪表必须存在、启用，且能源类型匹配。
- 产量大于 0 时，单位能耗按能耗量除以产量计算；正基线存在时计算偏离率。实际能耗超过填写的预警偏差时自动生成告警。
- 删除仍被能耗引用的仪表、仍有分表的仪表，或已有自动告警的能耗记录时，服务端返回明确的中文错误。
- CRUD 由 `ENERGY:*` 权限码控制；`ADMIN`、`ENERGY_ADMIN` 获得完整权限，分析角色获得查看权限。

## 数据库变更

Flyway 迁移 `V57__energy_management_crud.sql` 为两类能耗记录增加计量点、班次、订单、基线偏离及备注等字段，并创建仪表和告警台账。空库启动和已部署数据库均需正常执行该迁移。

## 当前边界

当前交付覆盖用户本次列出的中文展示、CRUD、错误提示与参考字段。它仍是 EMS 的管理台账切片：尚未接入真实仪表协议或自动采集；未实现电价/峰平谷结算、正式抄表审核流程、碳排核算、能耗预算和趋势/排名报表。以上不作为本次 CRUD 页面已完成的功能。
