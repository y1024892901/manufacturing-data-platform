# PLM 字段来源与功能差距

本文记录本项目 PLM 页面字段设计所参考的厂商产品资料。字段名称采用本系统的中文业务术语；新增描述字段为选填，用于提升工程资料的检索、适用范围识别和版本追溯能力。

## 页面字段设计

| 页面 | 参考资料中的常见属性/能力 | 本系统字段 | 用途 |
| --- | --- | --- | --- |
| 产品族 | 产品结构、产品组合及面向市场的产品信息 | 市场细分、负责人账号、产品族说明（选填） | 描述产品组合归属和责任人 |
| 产品版本 | 修订版、生命周期、适用产品配置 | 生命周期、生效日期、版本变更摘要（选填）、适用市场（选填） | 说明修订内容和版本生效范围 |
| 受控文档 | 文档修订、生命周期，以及与产品/工程对象关联 | 文档类型、版本、产品编码、密级、文件名、语言、生效日期、说明（选填） | 识别工程文档用途、语言和受控范围；当前 `file_name` 仅记录文件名，并不代表已提供文件库或签入/签出 |
| 工程基线 | 产品结构与工艺路线的版本组合及配置追溯 | 产品版本、BOM/工艺路线版本、基线用途（选填）、备注（选填） | 固定某一时点可追溯的工程配置 |
| 变更申请 ECR | 问题报告、原因、提案、紧急程度、影响对象、成本/进度影响 | 问题描述、变更原因、紧急程度、建议方案（选填）、计划生效日期（选填）；影响对象说明、风险、成本与进度影响（选填） | 判断变更必要性和初步影响范围 |
| 变更命令 ECO | 变更范围、受影响目标、修订目标与审批 | 变更范围（选填）、目标类型、目标编码（选填）、新版本 | 明确审批对象及拟产生的版本 |
| 变更通知 ECN | 已批准的变更内容、原因、生效日期和目标修订版 | 目标类型/编码/版本；变更内容、原因、生效日期（选填） | 记录已批准并待实施的工程变更 |
| EBOM/MBOM | BOM 多视图、结构比较、制造视图与工艺规划 | 当前提供 MDM 发布副本查询、明细查看、版本用量差异比较 | 复用 MDM 权威数据；PLM 通过 ECN 发起新版本，不直接改写 BOM |

## 对照当前项目的常见功能差距

依据当前 PLM 路由、页面和后端端点，系统已有产品族、产品版本、受控文档元数据、工程基线、MDM BOM 只读副本/版本比较，以及 ECR→ECO→ECN 变更链。以下是常见 PLM 能力中当前没有完整工作流或页面的部分：

1. **CAD/PDM 文件库**：CAD 文件上传、签入/签出、在线预览、版本比较、关联零部件和权限控制。当前文档页只有元数据与文件名。
2. **制造工艺规划**：从 eBOM 派生并维护 mBOM、工艺路线/工序、工装设备资源、工艺文件与生产可视化。当前 BOM 来源于 MDM，只读；工艺路线也由主数据治理维护。
3. **配置与变型管理**：选项、特征、兼容性约束、产品配置规则及按配置生成 BOM/基线。
4. **供应商协同**：供应商受控查看/提交 CAD、规范、变更评审与供应商零件版本。
5. **工程变更影响图谱**：从零部件、BOM、CAD、文档、工艺、质量和订单自动展开影响对象，并提供差异红线和传播追踪。
6. **质量闭环集成**：把不合格、CAPA/8D、可靠性问题与零件/文档修订及 ECR 建立追溯关系。
7. **项目与组合管理**：新产品阶段门、任务/交付物、资源与成本计划、里程碑和风险看板。

建议优先级：先做文件库与 CAD 关联、制造工艺规划、变更影响图谱；再做产品变型、质量追溯和供应商协同。实际优先级应结合企业 CAD 工具、制造流程及供应商访问策略确认。
