# WMS 字段设计与外部依据

仓库、上架、收货、调拨和盘点页面保留业务必填字段；新增的库区位置、批次追溯、托盘标识、日期、责任人和说明字段均为选填。收货由 ASN 与质检流程生成，库存余额与事务流水由库存服务维护，不允许在页面直接新增、改写或删除过账结果。

| 页面 | 新增的非必填字段 | 用途 |
|---|---|---|
| 仓库与库位 | 库区、巷道、货架、货格、额定承重、备注 | 补充库内位置层级与存储限制，便于定位和后续容量管理。 |
| 收货待检 | 供应商批次号、托盘 SSCC、生产日期、有效期、收货备注 | 在质检前补充供应商标签与物流单元追溯信息；有效期随合格库存进入库存余额。 |
| 上架作业 | 托盘 SSCC、有效期、装卸与上架说明 | 把收货批次与托盘及实际库位关联，支持按标签追踪和现场作业备注。 |
| 库存操作 | 来源系统、来源单号、操作原因 | 说明库存冻结、解冻、隔离、质量放行、报废或退供动作的业务来源。 |
| 库存调拨 | 调拨原因、外部参考单号、申请人、备注 | 记录调拨缘由及关联业务，便于审批、追踪和复盘。 |
| 盘点作业 | 盘点原因、负责人、备注；明细含库位、批次、账面数、实盘数、差异和复核状态 | 保留盘点范围与执行责任，并支持逐项录数、复核和差异过账。 |

## 外部参考

- SAP [Inbound Delivery Process](https://help.sap.com/docs/SAP_EXTENDED_WAREHOUSE_MANAGEMENT/3d97bec9bf1649099384bb8167df3cf2/88ad54fa2c9044b7b5406a511783589e.html)：入库流程涵盖到货通知、收货、创建仓库作业任务和确认任务；上架页据此把“开始上架”和“完成上架”拆开，并在完成时过账库存。
- GS1 [Global Traceability Standard](https://www.gs1.org/standards/gs1-global-traceability-standard/current-standard)：追溯应关联产品或批次与物流单元，并记录收货、检验和库存可用状态；据此补充供应商批次和托盘标识。
- GS1 [Logistic Label Guideline](https://www.gs1.org/standards/gs1-logistic-label-guideline/1-3)：物流标签可携带批次、序列号和日期字段；据此增加 SSCC、生产日期和有效期字段。

新增字段使用中文标签并允许为空；批次与物料一致性、库存非负、单据状态以及盘点复核仍由后端校验。
