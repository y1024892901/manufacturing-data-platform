# EMS 字段设计依据

本文件记录能源管理页面中新增的可选字段及其外部依据。字段用于演示业务流程，企业上线前仍需按仪表协议、计量制度和能源口径配置。

## 页面字段

| 页面 | 新增的非必填字段 | 用途 |
|---|---|---|
| 能源仪表 | 安装位置、上级仪表、仪表倍率、采集间隔、最近校准日期、数据来源、负责人、预警偏差 | 建立计量层级，说明读数来源和质量，便于安排抄表及校准 |
| 设备能耗 | 仪表编码、统计小时、运行小时、同期产出、同期基线、基线期间起止日期、预警偏差、班次、生产订单、备注 | 将能耗和计量点、运行时间、同一统计期的产量关联，形成单位能耗和偏差；标明比较基线所覆盖的日期 |
| 车间能耗 | 同期产出、同期基线、基线期间起止日期、预警偏差、班次、成本中心、备注 | 支持车间级能耗强度、基线对比和成本归属；标明比较基线所覆盖的日期 |
| 能耗告警 | 关联记录、偏离率、处置人、完成日期、异常原因、处置措施 | 为告警核查和纠正措施留出责任人与闭环信息 |

非必填字段都在表单中明确标为“非必填”；缺省值不参与强制校验。基线期间起始日期和结束日期可同时留空；填写时需同时提供且起始日期不能晚于结束日期。能耗单位产出自动以同一统计周期的能耗量除以产出量计算；基线偏离率以 `(实际能耗 - 基线) / 基线 × 100%` 计算。只有录入正基线和偏差阈值，且实际值超过阈值时才自动生成告警。已有记录的基线日期保持为空，不回填推断日期。

## 外部参考

- 美国能源部制造业能源管理指南指出，EnPI 可用于组织、设施、设备、系统或过程；计算时能源数据和产量数据应覆盖相同时间范围，且应与能源基线比较。因此设备、车间记录保留了统计期、产量、基线和偏离率字段。[DOE：确定能源绩效指标](https://www1.eere.energy.gov/manufacturing/eguide/iso_step_2_7.html)
- 美国能源部建议依据可靠数据和适合组织能源使用情况的时间段建立基线，记录并定期复核；所以设备和车间能耗增加了可选的基线期间起止日期，便于解释基线数值的适用范围。[DOE：建立能源基线](https://www1.eere.energy.gov/manufacturing/eguide/iso_step_2_8.html)
- 美国能源部指南建议持续监测能耗、显著能源使用及相关变量，并要求测量数据准确、可重复，校准用于保障分析可靠性。因此仪表页面增加了采集间隔、数据来源、校准日期和计量层级等可选字段。[DOE：测量、监测与分析绩效指标](https://www1.eere.energy.gov/manufacturing/eguide/iso_step_4_1.html)
- 能源评审应识别能源来源及其对应的设施、设备、系统和过程；数据采集细节取决于现场计量条件。因此能源类型、设备/车间归属、仪表关联与安装位置作为可选信息记录。[DOE：识别能源来源与用途](https://www1.eere.energy.gov/manufacturing/eguide/iso_step_2_2.html)

这些资料用于确定字段方向，不代表法定计量规范，也没有将任何外部数据写入本系统。
