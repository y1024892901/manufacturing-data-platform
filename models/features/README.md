# models/features/ — 特征定义与校验

## 技术栈
Python · pandas · pydantic（特征契约）

## 放什么代码

| 文件 | 内容 |
|---|---|
| `schema.py` | 特征契约：字段名、类型、值域、是否必填、业务含义 |
| `loader.py` | 从 `dws_prod_delay_features` 读取，做训练/推理的**同一份读取逻辑** |
| `validator.py` | 特征质量校验：缺失率、异常值、分布漂移 |
| `labels.py` | 标签定义：如何判定"实际延期" |

## 标签定义（必须写死在代码里并注释清楚）

```python
# 延期标签：实际完工日期 > 计划完工日期
# 宽限：允许 1 天误差（生产实际中存在跨日完工的合理情形）
# 排除：已取消订单、计划完工日期为空的订单
label = (actual_finish_date > plan_finish_date + timedelta(days=1)).astype(int)
```

## 干什么事情
1. **防止特征泄漏**：校验所有特征字段都是"计划完工日期之前可获得的信息"
   （这是模型最容易出错的地方——若特征含完工后的信息，模型 AUC 会虚高到 0.99，上线即失效）
2. 训练前做分布检查，特征缺失率 > 30% 直接报错而非静默填充
3. 记录每次训练用的特征快照，保证结果可复现
