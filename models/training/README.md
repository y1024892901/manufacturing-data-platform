# models/training/ — 模型训练

## 技术栈
LightGBM · scikit-learn（切分与指标）· pandas · matplotlib（评估图）

## 放什么代码

| 文件 | 内容 |
|---|---|
| `train_delay.py` | 延期风险模型训练主流程 |
| `split.py` | 时序切分：**按时间切分而非随机切分** |
| `evaluate.py` | 评估指标：AUC、KS、PR 曲线、混淆矩阵、分档准确率 |
| `tune.py` | 轻量超参搜索（演示系统不追求极致调参） |

## 关键设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 数据切分 | **时序切分**（前 80% 时间训练，后 20% 验证） | 随机切分会因未来信息泄漏导致指标虚高 |
| 评估指标 | 优先 **PR-AUC 与分档准确率** | 延期订单是少数类，单纯看 AUC 会误判模型质量 |
| 类别不平衡 | `scale_pos_weight` 调整 | 延期订单占比通常 10%~20% |
| 可解释性 | `pred_contrib=True` 预留 SHAP 接口 | 训练时就为归因做好准备 |
| 模型规模 | `num_leaves` 控制在 31 以内 | 演示数据量有限，大模型必然过拟合 |
| 随机种子 | 固定 `random_state=42` | 保证每次训练结果一致，**演示可复现** |

## 输出的评估报告（演示材料）

- 特征重要性排序（Top 15）
- 混淆矩阵与各风险等级的准确率
- **典型误判案例分析**（主动展示模型边界，比宣称"准确率 95%"更可信）
- 与"纯规则基线"的对比（证明机器学习确实带来了提升）

## 干什么事情
1. 训练完成后自动触发 `inference/predict_delay.py` 全量评分，结果写入 ADS
2. 模型文件与评估报告按时间戳版本化存入 `registry/`
3. 训练指标写入 JSON，供管理后台「模型管理」页展示
